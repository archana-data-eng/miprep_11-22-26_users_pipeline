# MiPrep AI User Data Cleaning & ETL Pipeline
- *Input:* Raw mock interview session logs (miprep_11-22-26_users_xlsx.xlsx)
- *Process:* Inspected schema, fixed shifted headers, standardized candidate names/roles, removed email whitespace, coerced invalid score symbols (-), and exported clean data to Excel & SQLite (Untitled0.ipynb).
- *Outcome:* Processed 100 user sessions (40 Completed with 73.54% avg score; identified 60 drop-off/technical error cases).
